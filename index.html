Control de calidad local y trazable

Obtenga una primera película de su FASTA antes de analizarlo, clasificarlo o incorporarlo a un dataset.

FASTAudit inspecciona cada registro sin enviar las secuencias a un servidor. Conserva el encabezado original, deriva un ID canónico configurable, separa campos estructurados, detecta conflictos de integridad y puede comparar dos FASTA por identidad exacta.

Principio de trabajo FASTAudit informa lo que encuentra. No corrige, recorta, renombra, imputa ni modifica automáticamente las secuencias o encabezados fuente.

Métodos

Qué verifica FASTAudit

ID canónico

Con delimitador |, un encabezado como 00000|cepa|año conserva su texto completo y deriva 00000 como ID canónico. El delimitador es editable.

Integridad ID–secuencia

Distingue encabezado duplicado, ID canónico duplicado, secuencia idéntica y el caso crítico de un mismo ID asociado a secuencias diferentes.

Campos del encabezado

Separa el encabezado por el delimitador elegido, exporta cada campo al CSV y señala registros cuyo número de campos difiere del patrón modal del dataset.

Longitud

Calcula nucleótidos por registro y resume mínimo, máximo, media y mediana. La longitud objetivo es un parámetro del usuario, no una regla fija.

Alfabeto IUPAC

Reconoce A, C, G, T y los códigos ambiguos R, Y, S, W, K, M, B, D, H, V y N. Otros caracteres se reportan como no-IUPAC.

Secuencia codificante

Cuando está activada, evalúa el marco 0: múltiplo de 3, ATG inicial, stop terminal canónico TAA/TAG/TGA y stops internos.

SHA-256 y huellas del dataset

Calcula una huella por secuencia y huellas globales independientes del orden para el multiconjunto de secuencias y para los pares ID–secuencia.

Comparación A↔B

Distingue IDs preservados, encabezados cambiados, secuencias modificadas, altas, bajas y secuencias exactas conservadas bajo otro ID.

Haplotipos exactos

Agrupa secuencias nucleotídicas idénticas sin inferir relaciones filogenéticas. Cada secuencia distinta recibe un identificador H001, H002, etc.

Convenciones y límites de interpretación

FASTAudit es una herramienta de inspección estructural e integridad de datasets. No sustituye revisión de cromatogramas, evaluación de calidad de lecturas, alineamiento, inferencia filogenética, clasificación taxonómica ni validación biológica.

  • El encabezado FASTA original se conserva; el ID canónico es un atributo derivado.
  • Con el delimitador por defecto |, el primer campo es el ID canónico. No se usa el guion - como separador automático porque puede formar parte de un identificador legítimo.
  • La normalización convierte la secuencia a mayúsculas y elimina espacios y saltos de línea; no elimina otros caracteres.
  • Los stops internos se buscan en marco 0 cuando el modo codificante está activo.
  • Los grupos de haplotipos y la comparación entre FASTA representan identidad exacta, no distancia genética.
  • FASTAudit no modifica el archivo fuente ni imputa caracteres ambiguos.
